# Lubb | تحليل بيانات المستفيدين من خدمات الرعاية الاجتماعية

مشروع **Lubb** يهدف إلى تحليل بيانات المستفيدين وتحويلها إلى مؤشرات واضحة تساعد على فهم خصائص المستفيدين، توزيع الخدمات، المناطق الإدارية، أسباب الدخول، والفئات العمرية والتعليمية، مع تقديم النتائج في تحليل قابل لإعادة التشغيل وداشبورد تنفيذي.

## 🔗 لوحة المعلومات التفاعلية

### [فتح لوحة بوصلة كبار السن](https://weamfayaab.github.io/kafaathakton1/outputs/dashboard/)

## أهداف المشروع
- فحص جودة البيانات وتوثيق الملاحظات المهمة.
- تحليل الخصائص الديموغرافية والخدمية للمستفيدين.
- إنشاء مؤشرات ورسوم قابلة لإعادة التشغيل باستخدام Python.
- تقديم داشبورد تنفيذي يدعم قراءة النتائج واتخاذ القرار.
- توثيق استخدام الذكاء الاصطناعي بطريقة مسؤولة.

## البيانات
تم تجهيز وتنظيف البيانات في ملف `original_analysis/FinalOne.ipynb`، ويعتمد التحليل النهائي على البيانات الناتجة في `data_clean/FinalData.csv`.

- عدد السجلات: **1,282**
- عدد الأعمدة: **14**
- نسبة السعوديين: **99.1%** بعد احتساب `سعودي` و`سعودي/ة`.
- متوسط العمر: **73.7 سنة**.
- عدد المناطق الإدارية: **14**.

### ملاحظة جودة البيانات
يوجد **136 سجلًا زائدًا متطابقًا بالكامل**. لم يتم حذفها تلقائيًا لأن البيانات لا تحتوي على **معرّف فريد للحالة أو المستفيد (ID)** يثبت أن التطابق تكرار إدخالي وليس حالات فعلية مختلفة تحمل الخصائص نفسها. لذلك تم الاحتفاظ بها مع التوصية بالتحقق من المصدر قبل الحذف.

## طريقة تشغيل التحليل

### Google Colab
1. افتح `analysis.ipynb`.
2. افتحه باستخدام Google Colab.
3. تأكد من توفر `data_clean/FinalData.csv` بنفس المسار.
4. اختر **Runtime → Run all**.
5. ستظهر فحوصات الجودة والتحليل والرسوم، ويتم حفظ الرسوم داخل `outputs/figures/`.

### Jupyter Notebook
ثبت المتطلبات:
```bash
pip install pandas numpy matplotlib openpyxl jupyter
```

ثم شغّل:
```bash
jupyter notebook
```

افتح `analysis.ipynb` ثم اختر **Run All**.

## تشغيل الداشبورد
يمكن فتح النسخة المنشورة مباشرة من الرابط أعلى الصفحة، أو فتح الملف محليًا من:

`outputs/dashboard/index.html`

باستخدام **Chrome أو Edge**.

## مخرجات المشروع
- `FinalOne.ipynb`: ملف تنظيف وتجهيز البيانات قبل التحليل النهائي.
- `analysis.ipynb`: التحليل وفحوصات الجودة والرسوم.
- `FinalData.csv`: البيانات النهائية المستخدمة في التحليل.
- `outputs/dashboard/index.html`: الداشبورد التنفيذي المنشور.
- `executive_summary.pdf`: الملخص التنفيذي.
- `ai_usage_log.md`: توثيق استخدام الذكاء الاصطناعي والتحقق البشري.

## الاستخدام المسؤول للذكاء الاصطناعي
استُخدم الذكاء الاصطناعي للمساعدة في تنظيم التحليل، تطوير العرض والداشبورد، وتحسين التوثيق. جميع الأرقام والمؤشرات محسوبة من `FinalData.csv` باستخدام Python، ولم يتم استخدام الذكاء الاصطناعي لاختراع قيم أو تعديل البيانات الأصلية. القرارات التي تحتاج دليلًا، مثل حذف التكرارات، تُترك للتحقق البشري عند عدم توفر معرّف فريد أو دليل كافٍ.
